7-Animation

1. Animation Principles

1.1 Introduction to Animation

Animation 的核心是：让事物动起来。
从图形学角度看，它就是把场景表示为时间的函数，再连续输出图像序列，形成运动感。

常见帧率：

  • Film：24 fps
  • Video：30 fps
  • VR：90 fps

1.2 Keyframe Animation

1.2.1 Keyframes and Tweening

关键帧动画的基本思路是：

  • 动画师给出少量 keyframes
  • 中间帧由助手或计算机生成，这叫 tweening

也就是说，动画师主要决定关键姿态，系统负责把中间过程补出来。

1.2.2 Keyframe Interpolation

可以把一帧看成“很多参数组成的向量”，然后对这些参数随时间做插值。
最简单的是线性插值，但通常不够平滑，所以更常用 spline 一类方法来得到更自然、可控的运动。

2. Physical Simulation

2.1 Physically Based Animation

2.1.1 Newton’s Law

物理动画的出发点是牛顿定律：

力决定加速度，加速度再决定速度和位置的变化。

2.1.2 Physically Based Animation

物理动画不是直接画“它应该怎么动”，而是先给定力、质量、约束，再通过数值模拟让运动自己产生。
比如抛体、布料、液体，都属于这一路思路。

2.2.1 Basic Spring Model

最简单的弹簧遵循 Hooke 定律，弹力和形变量成正比。

2.2.3 Damping

如果只有弹簧力，系统会一直振荡。
所以要引入阻尼，让能量逐渐损失。

最简单的阻尼直接和速度相关，但会把整体运动也一起减慢。
更合理的是 internal damping，只对弹簧方向上的相对运动做阻尼，这样不会把整团物体的整体平移和旋转都无脑减速。

2.2.4 Structures from Springs


很多复杂物体都可以看成弹簧网络：

  • rope
  • cloth
  • hair
  • mass spring mesh

而且系统的表现很大程度由连接结构决定。
不同连边方式会影响：

  • 是否抗拉伸
  • 是否抗剪切
  • 是否抗弯曲

所以 mass-spring 不只是“有弹簧就行”，结构本身就决定了物理行为。

2.3 Particle Systems

2.3.1 Particle System Basics

粒子系统把一个动态系统表示成大量粒子的集合。
每个粒子都有自己的位置、速度，并受到各种力的作用。

它的优点是：

  • 直观
  • 好实现
  • 易扩展

问题是：粒子很多时会很贵，还常常需要邻域搜索或加速结构。

2.3.2 Particle System Forces

常见粒子力包括：

  • 吸引 / 排斥
  • 重力
  • 弹簧力
  • 推进力
  • 阻尼、摩擦、空气阻力
  • 碰撞响应

一个粒子系统每一帧通常做这些事：

  1. 生成新粒子（如果需要）
  2. 计算每个粒子的力
  3. 更新位置和速度
  4. 删除死亡粒子
  5. 渲染

2.3.3 Particle-Based Examples

课程里给了不少粒子系统例子：

  • 星系模拟
  • 粒子流体
  • flocking / boids
  • 分子动力学
  • crowd / rock dynamics

这些都说明：简单局部规则叠加起来，可以涌现复杂群体行为。

2.4 Rigid Body and Fluid Simulation

2.4.1 Rigid Body Simulation

刚体模拟和粒子类似，只是状态更多。
除了位置和速度，还要考虑：

  • 旋转角
  • 角速度
  • 力矩
  • 转动惯量

所以刚体相当于“带旋转自由度的粒子”。

2.4.2 Position-Based Fluid Method

课程里讲了一个简单的 position-based fluid 思路：

  • 把水看成许多小粒子
  • 假设不可压缩，也就是密度应尽量保持常数
  • 若某处密度偏了，就通过改粒子位置去纠正
  • 更新时可以沿密度梯度方向做修正

它的好处是直观、稳定，适合图形学中的实际模拟。

2.4.3 Eulerian and Lagrangian Views

模拟大量物质时有两种经典视角：

  • Lagrangian：跟着粒子走
  • Eulerian：固定在空间网格上看物质流过

前者像追踪每只鸟，后者像站在固定位置观察所有鸟飞过。

2.4.4 Material Point Method

MPM（Material Point Method） 是 Eulerian 和 Lagrangian 的混合：

  • 粒子携带材料属性
  • 网格负责数值积分
  • 粒子把信息传给网格
  • 网格更新后再插值回粒子

所以它兼顾了粒子法和网格法的一些优点，在复杂材料模拟里很常见。

3. Kinematics and Character Control

3.1 Forward Kinematics

3.1.1 Articulated Skeleton

运动学里常把角色看成一个 articulated skeleton。
它通常是树结构，由关节连接不同骨段。

常见关节类型：

  • pin joint：1D 旋转
  • ball joint：多自由度旋转
  • prismatic joint：平移

3.1.2 Forward Kinematics of a Simple Arm

FK（Forward Kinematics） 的意思是：

  • 动画师给出关节参数
  • 系统根据骨架关系算出末端位置

例如二维两段手臂里，给定每段角度，就能算出 end effector 的位置。
所以 FK 是“已知角度，求位置”。

3.2 Inverse Kinematics

3.2.1 Basic Idea of IK

IK（Inverse Kinematics） 正好相反：

  • 动画师给出 end effector 想到的位置
  • 系统反过来求各个关节角度

所以 IK 是“已知目标位置，求姿态参数”。

3.2.2 Why IK is Hard

IK 难主要因为：

  • 可能有多个解
  • 这些解在 configuration space 里可能分散，也可能连在一起
  • 有时根本无解

所以 IK 本质上是一个带约束的求解 / 优化问题。

3.2.3 Numerical IK

一般的多连杆 IK 往往不能手推解析解，于是常用数值法：

  1. 先选一个初始姿态
  2. 定义误差函数
  3. 算误差对参数的梯度
  4. 做 gradient descent、Newton method 等优化

3.2.4 Style-Based IK

更进一步的 IK 还会考虑风格，不只是“到没到目标”，还要“像不像某种动作风格”。
这就是 style-based IK 的方向。

3.3 Rigging and Motion Capture

3.3.1 Rigging

Rigging 可以理解为角色的高层控制系统。
它提供更直观的控制手柄，让动画师更快地调姿态、形变和表情。

它像木偶身上的线，但制作成本很高，因为既要艺术理解，也要技术实现。

3.3.2 Blend Shapes

除了骨骼，也可以直接在表面之间做插值。
比如先建很多张表情形状，再通过权重混合它们，这就是 blend shapes。

最简单的做法是顶点位置线性组合，再让权重随时间变化。

3.3.3 Motion Capture

Motion Capture 是一种 data-driven 动画方法：

  • 记录真实表演
  • 从数据中提取姿态随时间的变化
  • 再把这些运动迁移到角色上

优点：

  • 快
  • 真实感高

缺点：

  • 设备复杂且昂贵
  • 捕到的动作不一定符合艺术需求，后续还得改

3.3.4 Challenges of Facial Animation

面部动画有个著名问题叫 uncanny valley（恐怖谷）。
角色越接近真人，观众反而越容易在“不够真”的细节上感到不适。
所以面部动画往往比一般动作更难做好。

4.2 Euler Method and Its Problems

4.2.1 Explicit Euler Method


最基本的方法是 Explicit Euler：

它的优点是简单，缺点也很明显：不准，而且常常不稳定。

4.2.2 Errors and Instability

Euler 法有两个核心问题：

  1. 误差积累

    • 每一步都会有近似误差
    • 步长越大，误差越大

  2. 不稳定

    • 误差可能不断放大
    • 最终导致系统发散、爆炸

所以在动画模拟里，稳定性是个很严肃的问题。

4.3 Improving Stability

4.3.1 Midpoint Method

Midpoint 方法会先估一个中点，再用中点处的导数更新：

它比显式 Euler 更准，也更稳定。

4.3.2 Modified Euler

Modified Euler 的思路是：
用起点和终点速度的平均值来更新位置。
比普通 Euler 更好，但仍然属于显式方法的改进版。

4.3.3 Adaptive Step Size

自适应步长会根据误差自动调节 。

一种常见思路：

  • 先走一步
  • 再走两步
  • 比较这两个结果
  • 若误差太大，就缩小步长重算

它很实用，但有时会被迫把步子切得很小。

4.3.4 Implicit Euler

Implicit Euler 用未来时刻的导数做当前步更新：

它通常需要解非线性方程，计算更麻烦，但稳定性明显更好。
所以在 stiff system 里很常见。

4.3.5 Runge-Kutta


Runge-Kutta 是一族更高级的 ODE 数值方法。
其中最常用的是 RK4。

它通过多次采样导数再加权组合，得到更高阶、更准确的更新。
优点是对非线性系统表现更好。

4.3.6 Position-Based / Verlet Integration

这一类方法的核心是：

  • 先往前走一步
  • 再直接约束粒子的位置
  • 再由新位置反推速度

优点：

  • 快
  • 简单
  • 稳定

缺点：

  • 不够物理严格
  • 会耗散能量
  • 更像是“为了效果和稳定性服务”的方法
