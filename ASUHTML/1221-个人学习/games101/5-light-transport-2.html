5.2 Path Tracing Algorithm

5.2.1 操作思想与方法

积分结果：Radiance，某点 方向 上的光。
积分对象：采样得到的 一组 入射方向

若指定当前点和出射方向，从半球上按 采样若干个方向 ，就有：

最基本的路径追踪思想
对于表面点 和观察方向 ：

  1. 随机采样一个入射方向
  2. 发出一条从 出发的光线
  3. 如果打到光源，就得到直接贡献
  4. 如果打到别的物体，就递归计算那个点的出射辐亮度
  5. 乘上当前点的 BRDF、余弦项、pdf 校正

5.2.2 问题与解决->得到算法

5.2.2.1 基本算法与其问题
//分布式光线追踪
shade(p,wo)
	Randomly choose N directions wi~pdf //sample,N=1 is Path Tracing
	Lo = 0.0
	For each wi
		Trace a ray r(p,wi)
		If ray r hit the light
			Lo += (1/N)*L_i*f_r(p,wi,wo)*(n*wi) / pdf(wi) //direct illumination
		Else If ray r hit an object at q
			Lo += (1/N)*shade(q,-wi)*f_r(p,wi,wo)*(n*wi) / pdf(wi)
	Return Lo

这个算法存在（1）爆炸和（2）递归难以停止的问题！！！

->When Number of Sample = 1 ->Path Tracing

# to avoid multiple rays boom(N^bounces), let N=1
# to solve noisy effection when N=1, for each pixel, shoots multiple paths

ray_generation(camPos, pixel)
	Uniformly choose N sample positions within the pixel
	pixel_radiance = 0.0

	For each sample in the pixel
		Shoot a ray r(camPos, cam_to_sample)
		If ray r hit the scene at p
		pixel_radiance += 1 / N * shade(p, sample_to_cam)
	Return pixel_radiance
	
# to solve the endless recursive algorithm, using probality *p* to stop
# so the E(bounces)=p/1-p
# let L_o divided by p, so the E(L_o) will be fixed to L_o

shade(p, wo) 
	Manually specify a probability P_RR 
	Randomly select ksi in a uniform dist. in [0, 1] 
	
	If (ksi > P_RR) 
		return 0.0; 
	
	Randomly choose ONE direction wi~pdf(w) 
	Trace a ray r(p, wi) 
	If ray r hit the light 
		Return L_i * f_r * cosine / pdf(wi) / P_RR 
	Else If ray r hit an object at q
		Return shade(q, -wi) * f_r * cosine / pdf(wi) / P_RR
