6.5 Geometry-related Textures Shading

6.5.1 法线贴图（Normal Mapping）——作用

法线贴图用于在 不改变几何结构 的前提下改变每个像素的 normal，从而改变光照结果。

核心思想：纹理直接存储 normal 信息，fragment shader 读取该 normal 并替换原始几何法线参与光照计算，因此可以表现砖墙、织物、划痕等细节结构，同时 position、triangle、轮廓与真实遮挡关系保持不变，仅改变 shading。

6.5.2 Bump Mapping——实现方法和效果

Bump mapping 通过 height map 的局部梯度扰动原始 normal 来模拟表面凹凸细节，其中 height map 记作 ，通过计算 与 得到局部倾斜方向，再构造扰动 normal 并参与光照计算，因此视觉上产生细节起伏但几何结构不发生变化。

6.5.2.1 局部法线


这是一个二维的情况，只要我们知道了定义好的h(u)上的变化程度，我们就可以根据h(u+1)-h(u)乘一个常数c得到dp，我们就有了斜边方向向量(1,dp)，法线就是在这个局部坐标系上的垂直的向量n，也就是(-dp,1)。
扩展到三维的情况，如下：

  • Original surface normal n(p) = (0, 0, 1)
  • Derivatives at p are
    • dp/du = c1 * [h(u+1) - h(u)]
    • dp/dv = c2 * [h(v+1) - h(v)]
  • Perturbed normal is n = (-dp/du, -dp/dv, 1).normalized()
    此时我们只解决了局部坐标系的问题，因此我们引入矩阵TBN
6.5.2.2 TBN 矩阵

TBN矩阵的作用是：建立一个局部切线空间（tangent space）坐标系，把纹理空间里的法线（例如 normal map 或 bump 推出来的法线）转换到 world space 或 view space 参与光照计算。

它由三个互相正交的向量组成：

  • T = tangent（沿 u 方向）
  • B = bitangent（沿 v 方向）
  • N = normal（原始几何法线）

6.5.2.3 实现流程
input:  
    normal n  
    texcoord (u, v)  
    height map h(u, v)  
  
step1:  
    sample height difference  
    dU = h(u+du, v) - h(u, v)  
    dV = h(u, v+dv) - h(u, v)  
  
step2:  
    build local tangent space matrix  
    TBN = [T B N]  
  
step3:  
    compute perturbed normal in tangent space  
    ln = (-dU, -dV, 1)  
  
step4:  
    transform to world space  
    n' = normalize(TBN * ln)  
  
step5:  
    use new normal for lighting  
    result_color = lighting(n')

最终效果是改变像素级光照分布来模拟表面细节起伏，但不会改变模型轮廓，也不会产生真实几何位移；若需要真实位移效果，应使用 displacement mapping。

6.5.3 Displacement Mapping

6.5.3.1 Actually moves the vertices

Displacement mapping 使用与 bump mapping 相同的 height map：

但不同之处在于：bump mapping 只改变法线方向：
displacement mapping 直接沿法线方向移动顶点位置：

改变 position -> 改变 normal -> 改变物体轮廓 -> 改变真实阴影

6.5.3.2 实现方法

首先沿法线方向移动顶点：

float h = height(u, v);

position = position + normal * h;

float dU = height(u + du, v) - h;
float dV = height(u, v + dv) - h;

Vector3f ln(-dU, -dV, 1.0);

normal = normalize(TBN * ln);
