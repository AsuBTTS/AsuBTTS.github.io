2-Rasterization

1. What is Rasterization

光栅化（Rasterization）指： 将连续几何图元（通常是三角形）转换为屏幕像素的过程
屏幕本质是一个二维像素数组：Image = 2D array of pixels
for each pixel's color：color = (R, G, B)
Rasterization = sampling in 2D space

2. MVP->Rasterization

Model → View → Projection（MVP） 得到clip space position

随后执行： perspective division

得到： NDC（Normalized Device Coordinates） x,y,z ∈ [-1,1]

接着执行： viewport transform

映射到屏幕空间： x ∈ [0,width] y ∈ [0,height]

得到： triangle 的屏幕空间坐标

Rasterization 的输入：

screen-space triangle

Rasterization 的目标：

确定哪些像素被覆盖，以及这些像素的属性值是多少

例如：

color
depth
normal
texture coordinate
shading result

// acceleration method : bounding box

3.3 inside triangle ： three cross

using cross：

triangle {P0, P1, P2}
for each being checked point:

(P1-P0) × (Q-P0) //.cross()
(P2-P1) × (Q-P1)
(P0-P2) × (Q-P2)

if the same sign
Q ∈ triangle
else
Q ∉ triangle

4. Advanced Sampling : for Aliasing

4.1 Aliasing

光栅化本质是采样：continuous signal → discrete pixels

走样是因为存在频率变化极高的地方，产生了锯齿

反走样就是减少这些频率变化剧烈的地方


先滤波再采样
filter → sample

4.2 Area Sampling

思想：
pixel 本质不是一个点而是一个小区域，因此像素值应等于 triangle 在 pixel 内覆盖面积比例
伪代码： 

for each triangle:  
	compute bounding box  
	for x in (xmin,xmax):  
		for y in (ymin,ymax):  
			covered_area = compute_triangle_pixel_intersection_area()  
			pixel[x][y] = covered_area / pixel_area

4.3 超采样（Supersampling / SSAA）

思想：使用多个子采样点近似面积积分，把一个 pixel 拆成 N×N subpixels，在每个 subpixel center 进行 inside test，再取平均值作为最终 pixel 值，即 pixel_value = inside_count / sample_count，本质是提高 sampling frequency 来逼近真实面积覆盖率，从信号角度理解就是提升采样率减少高频 aliasing
例如对 pixel(x,y) 做 2×2 supersampling，可以在这个 pixel 内取 4 个 sample：

(x+0.25,y+0.25)
(x+0.75,y+0.25)
(x+0.25,y+0.75)
(x+0.75,y+0.75)

for each triangle:  
	compute bounding box  
	for x in (xmin,xmax):  
		for y in (ymin,ymax):  
			inside_count = 0  
			for each sub_sample s in pixel(x,y):  
				if inside(triangle,s):  
					inside_count++  
			pixel[x][y] = inside_count / sample_count

特点：边缘平滑效果明显，可以很好近似 area sampling，但代价是 shading 与 depth test 计算次数增加为原来的 N² 倍，例如 4×SSAA 计算量变为 4 倍，16×SSAA 变为 16 倍，因此性能成本较高

4.4 MSAA（Multi-Sample Anti-Aliasing）

思想：SSAA 的优化版本，只对 geometry coverage 进行多次采样，而 shading 只计算一次，即 pixel 内多个 sample position 判断是否在 triangle 内得到 coverage mask，再根据覆盖比例混合颜色，从而减少 shading 次数降低计算成本，同时保持 edge smoothing 效果

伪代码： 

for each triangle:  
	compute bounding box  
	for each pixel:  
		coverage = 0  
		for each sub_sample s:  
			if inside(triangle,s):  
				coverage++  
			pixel_color = shading_result * coverage / sample_count

特点：相比 SSAA 计算量显著下降，因为 shading 只执行一次，但仍能有效改善 triangle edge 的 jaggies，因此成为实时渲染中常用抗锯齿方法，不过仍然需要额外 sample storage 和 memory bandwidth
